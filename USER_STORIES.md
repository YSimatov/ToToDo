# Пользовательские истории (Lab 1)

## 1. Добавление и выполнение задач
**Как** пользователь,  
**Я хочу** иметь возможность добавлять задачи и отмечать их как выполненные,  
**Чтобы** не пропустить то, что для меня важно.

**Основной сценарий:**
1. Пользователь заходит в приложение.
2. Выбирает день в календаре.
3. В правой части интерфейса нажимает кнопку добавления задачи.
4. Указывает время начала (и по желанию конца).
5. Вводит название и описание задачи, сохраняет её.
6. Задача появляется в списке.
7. При выполнении задачи пользователь нажимает чекбокс, отмечая её как выполненную.

**Альтернативный сценарий:**
1. Пользователь пытается сохранить задачу без названия или времени начала.
2. Приложение не сохраняет задачу и подсвечивает обязательные поля.

---

## 2. Переключение темы оформления
**Как** пользователь,  
**Я хочу** иметь возможность переключить внешний вид приложения на темный или светлый,  
**Чтобы** обеспечить комфортный для меня вид в зависимости от освещения.

**Основной сценарий:**
1. Пользователь заходит в приложение.
2. Нажимает на кнопку переключения темы в верхней части приложения.
3. Цветовая схема приложения меняется (с темной на светлую или наоборот).
4. Выбранная тема сохраняется при следующем входе.

---

## 3. Управление задачами (Редактирование и Удаление)
**Как** пользователь,  
**Я хочу** иметь возможность изменять и удалять задачи,  
**Чтобы** поддерживать актуальность моего расписания при изменении планов.

**Основной сценарий (Редактирование):**
1. Пользователь выбирает день с задачей.
2. Нажимает на кнопку редактирования (или иконку карандаша/троеточие) у задачи.
3. Изменяет данные (время, название, описание).
4. Сохраняет изменения.
5. Задача в списке обновляется.

**Основной сценарий (Удаление):**
1. Пользователь выбирает день с задачей.
2. Нажимает на кнопку удаления (корзина) у задачи.
3. Подтверждает удаление во всплывающем окне.
4. Задача исчезает из списка.

---

## 4. Визуализация занятости (Индикаторы в календаре)
**Как** пользователь,  
**Я хочу** видеть на календаре дни, на которые выставлены задачи,  
**Чтобы** быстро понимать свою загруженность без необходимости просматривать каждый день.

**Основной сценарий:**
1. Пользователь открывает календарь (главный экран).
2. Видит кружки/точки на днях, где есть задачи.
3. При добавлении новой задачи на пустой день, индикатор появляется.
4. При удалении всех задач с дня, индикатор исчезает.

---

## 5. Уведомления о задачах
**Как** пользователь,  
**Я хочу** получать уведомления от приложения,  
**Чтобы** не пропустить начало важной задачи.

**Основной сценарий:**
1. Пользователь создал задачу с указанным временем.
2. За час (или другое настроенное время) до начала задачи приложение показывает уведомление (в интерфейсе или браузерное уведомление).
3. Пользователь видит напоминание.

**Альтернативный сценарий:**
1. Время задачи прошло, пока приложение было закрыто.
2. При открытии приложения пользователь видит список пропущенных задач.

---

## 6. Регистрация и Авторизация (Lab 6 Requirement)
**Как** пользователь,  
**Я хочу** иметь возможность зарегистрироваться и войти в свой аккаунт,  
**Чтобы** мои задачи были доступны только мне и сохранялись между сессиями.

**Основной сценарий:**
1. Незарегистрированный пользователь заходит на сайт.
2. Видит форму входа/регистрации.
3. Вводит логин и пароль для регистрации.
4. Попадает на главный экран календаря.
5. При повторном входе вводит логин и пароль.
